# 001: 문제 하나의 코드·메모 저장과 복원

## 목적

사용자가 하나의 실제 학습 자료로 앱을 사용해 보고, Orca에서 구현과 검토가 서로 다른 에이전트에게 배정되는 과정을 확인한다.

## 사용자 흐름

앱 실행 → 데이터분석 연습 문제 열기 → C++ 코드와 생각해볼점 수정 → 저장 → 앱 종료 → 재실행 → 저장 내용 확인.

## 범위

- 개인용 Linux 데스크톱 앱. 작은 Electron 앱을 기본 후보로 사용한다. 기존 의존성과 실행환경을 확인하고 구성한다.
- 고정된 연습 문제 하나. 제목, C++ 코드 편집 영역, 학습 메모, 저장 버튼과 상태 표시.
- 샘플 코드는 `samples/data-analysis.cpp`를 사용한다. 원본 출처는 사용자 폴더의 `데이터분석/sol1.cpp`다. 정답 통과 여부는 미확인이다.
- 사용자 기록은 저장소 밖의 앱 사용자 데이터 디렉터리에 저장한다. 앱 버전 변경이나 작업공간 변경으로 기록이 덮어써지면 안 된다.
- 저장 실패 시 오류를 보여 주고 편집 중인 코드를 유지한다. 손상된 저장 파일은 조용히 초기화하지 않는다.
- UI는 한국어이며, 현재 연습 문제와 저장 상태를 명확하게 보여 준다.

## 완료 조건

1. 실행 가능한 앱에 샘플 코드와 메모 편집 영역이 보인다.
2. 코드와 메모를 변경하고 저장한 뒤 프로세스를 종료·재시작해도 값이 유지된다.
3. 저장 실패 시 성공으로 표시하지 않으며 편집 내용이 사라지지 않는다.
4. 기존 원본 학습 파일은 변경되지 않는다.
5. README에 실제로 확인한 설치·실행·검증 방법이 있다.
6. 구현 담당의 결과 보고와 검토 담당의 독립 보고가 있다.

## 후속 작업

여러 문제 관리, 편집기 기능 확장, 문제별 AI 대화와 아이디어 저장, 로컬 코드 실행, 프로그래머스 제출 연동 검증, 학습 기록 기반 추천.
